# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

This is a small, single-maintainer project. Read `README.md` (what it does,
how to run it) and `docs/VISION.md` + `docs/ARCHITECTURE.md` (why it's
built this way) before making changes — together they're faster to read
than any summary here, and the codebase itself (a dozen files under
`src/ylearn/`) is small enough to read directly rather than relying on
notes that can drift out of date.

Don't let this file grow into a second copy of the architecture docs or
the codebase. If something is worth writing down, it belongs in one of
those, not here.

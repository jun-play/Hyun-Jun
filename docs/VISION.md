# 프로젝트 비전

> 아래는 이 프로젝트를 시작하게 된 생각을 정리한 것이다.

유튜브에는 정말 많은 정보가 올라온다 — 개업 회계사가 되는 법, 돈을 많이
버는 법, 돈 관리를 어떻게 해야 하는지, 와이프와 혹은 가장으로서 행복한
삶을 누리려면 어떻게 해야 하는지. 전자도서관이나 알라딘 같은 곳에도
같은 주제를 다루는 책이 산더미처럼 쌓여 있다.

문제는 이 정보가 너무 많고 흩어져 있다는 것이다. 좋은 조언과 뻔한 말이
섞여 있고, 같은 말이 영상 100개에서 반복되기도 하고, 정말 필요한 한
문장을 찾으려면 몇 시간짜리 영상을 다 봐야 한다.

이 프로젝트가 하려는 일은:

1. **수집(ingest)** — 유튜브 영상(자막), 그리고 앞으로는 책 발췌까지,
   "삶을 바꾸는 데 도움이 되는" 자료를 하나의 파이프라인으로 모은다.
2. **분류(classify)** — 그 내용을 삶의 영역(도메인)별로 나눈다: 돈 관리,
   부의 축적, 커리어/전문직 개업, 가족/부부 관계, 행복한 삶 전반.
   (`data/domains.yaml` — 코드 수정 없이 확장 가능)
3. **증류(distill)** — 원문에서 실제로 실행 가능한 조언만 뽑아내
   "조언 카드"(요약 + 실행 항목 + 원문 인용)로 압축한다. 과장하거나
   지어내지 않고, 원문에 있는 것만 근거로 삼는다.
4. **질의응답(ask)** — "회계사 개업하려면 뭐부터 준비해야 해?" 같은 구체적
   질문을 던지면, 여러 출처에서 뽑아낸 조언 카드 중 관련된 것을 찾아
   하나로 종합해서 답한다. 어떤 자료를 근거로 했는지도 항상 밝힌다.

즉, "인터넷과 책 전체"라는 방대한 자료를 그대로 나에게 던지는 대신,
내 삶의 구체적인 영역별로 **정제된 조언의 축적물**을 만들어가는 개인용
지식 시스템을 만드는 것이 목표다.

## 지금 버전(MVP)에서 의도적으로 하지 않은 것

- 유튜브 채널을 자동으로 크롤링해서 무제한으로 긁어오는 것은 하지 않는다.
  (저작권/이용약관, 그리고 "질보다 양"이 되는 것을 피하기 위해 사용자가
  의미 있다고 판단한 영상을 하나씩 골라 넣는 방식으로 시작한다.)
- 전자도서관/알라딘 자동 스크래핑은 하지 않는다. 대신 사용자가 합법적으로
  읽은 내용을 직접 요약/발췌해서 넣는 `TextAdapter`로 같은 파이프라인에
  태울 수 있게만 해둔다.
- 정교한 임베딩/벡터DB 대신 의존성 없는 TF-IDF 검색으로 시작한다.
  (`docs/ARCHITECTURE.md`의 "향후 개선" 참고)
